# 课堂点名软件（RollCall）

极简桌面课堂点名工具，单文件免安装，运行于 Windows 10 / 11，浅色极简风格。

## 功能特性

- 单文件 `RollCall.exe`，自带全部运行库，**免安装、无需额外运行时**。
- 首次使用导入花名册（`.xlsx` / `.xls`），严格校验表头（序号/学号/姓名/班级）、跳过空行、学号重复会报错。
- **走马灯抽选效果**：点名时学生信息快速滚动闪过，达到设定时长后自动停下、显示被点名学生（可开关、可调时长）。
- 四种点名规则：随机 / 按序号 × 计重复 / 不计重复。
- 记录自动写入运行目录 `RollCallRecord/record.xlsx` 的当天日期列。
- 同一天再次打开会跳过已点名学生；点名中途改规则会立即按新规则刷新。

## 使用步骤

1. 下载 `RollCall.exe`（见本仓库 [Releases](https://github.com/papercatno1/RollCall/releases)），放到任意目录（建议单独建一个文件夹，数据会保存在该目录下）。
2. 双击运行，窗口默认 640×480，可最大化/拉伸。
3. **首次使用**（进入初始化界面，此时无菜单栏）：
   - 点击「下载模板」保存 `namelist模板.xls`；
   - 用 Excel 填写模板（四列：序号 / 学号 / 姓名 / 班级）；
   - 点击「选择花名册文件」导入填好的文件；
   - 导入成功后，软件生成 `RollCallRecord/record.xlsx` 并进入点名主界面。
4. **点名**：
   - 点击「现在开始点名啦！」；
   - 若启用了走马灯：学生信息会先快速滚动闪过，达到设定时长（默认 0.5 秒）后**自动停下**并显示被点名学生，此时下方三个按钮才可点击；
   - 若关闭了走马灯：直接显示被点名学生；
   - 点击「已到 / 请假 / 未到」记录，随后自动进入下一位学生。
5. **停止**：点击右下角「停止并退出」，确认后保存并退出。

## 点名规则（菜单「配置 → 点名规则…」）

四种规则（单选，首次默认「每次随机计重复」）：

- 每次随机计重复
- 每次随机不计重复
- 按序号顺序不计重复
- 按序号顺序计重复

另有走马灯两项设置：

- **启用走马灯抽选效果**：复选框，默认开启；
- **自动停下时长**：输入框，100～10000 的整数（单位毫秒），默认 500（即 0.5 秒）。

规则说明：

- **计重复**：优先点历史记录轮次最少的学生（先点从未被记录过的，全都有记录后点轮次最少的一批，轮次相同则整批候选）。
- **不计重复**：不考虑历史记录，全体学生等概率（随机）或按序号顺序。
- 每次会话内，同一学生在一轮中不会重复出现；一轮结束自动开始新一轮。
- 点名中途修改规则后，界面会立即按新规则刷新被点名学生（原学生不写入记录）。

## 数据说明

- `RollCallRecord/record.xlsx`：前四列是学生信息（序号/学号/姓名/班级），之后每一列是一次点名的日期列（列名 `YYYY-MM-DD`），单元格值为「到 / 假 / 旷」。
- `RollCallRecord/config.json`：保存 `strategy`（点名规则）、`marquee`（是否启用走马灯）、`marquee_duration`（自动停下时长，毫秒）。
- 再次运行时，只要 `RollCallRecord/record.xlsx` 存在且含有学生信息，即直接进入点名主界面。

## 开发与打包

- 源码在 `src/`，入口为 `src/main.py`，打包配置为 `RollCall.spec`。
- 依赖：Python 3.12、PySide6、openpyxl、xlrd、PyInstaller。
- 在仓库根目录执行 `python -m PyInstaller RollCall.spec`，产物为 `dist/RollCall.exe`。
