# 课堂点名软件（RollCall）

极简桌面课堂点名工具，单文件免安装，运行于 Windows 10 / 11。

## 交付物

- `dist/RollCall.exe` —— 单文件可执行程序，自带全部运行库，**无需安装、无需额外运行时**。
- `namelist模板.xls` —— 花名册模板（软件内也可直接下载）。

## 使用步骤

1. 把 `RollCall.exe` 放到任意目录（建议单独建一个文件夹，因为数据会保存在该目录下）。
2. 双击运行，窗口默认 640×480，可最大化/拉伸。
3. **首次使用**：进入初始化界面
   - 点击「下载模板」保存 `namelist模板.xls`；
   - 用 Excel 填写模板（四列：序号 / 学号 / 姓名 / 班级）；
   - 点击「选择花名册文件」导入填好的 `.xlsx` 或 `.xls` 文件；
   - 导入成功后，软件会在运行目录下生成 `RollCallRecord/record.xlsx`，并进入点名主界面。
4. **点名**：点击「现在开始点名啦！」→ 屏幕中央显示学号（上一行）+ 姓名（下一行，更大），
   下方三个按钮「已到 / 请假 / 未到」→ 点击后自动记录到当天日期列，并显示下一位学生。
5. **停止**：点击右下角「停止并退出」，确认后保存并退出。
6. **配置**：菜单栏「配置 → 点名规则…」，四选一：
   - 每次随机计重复
   - 每次随机不计重复
   - 按序号顺序不计重复
   - 按序号顺序计重复

## 数据说明

- 运行目录下 `RollCallRecord/record.xlsx`：前四列为学生信息，之后每一列是一次点名的
  日期列（列名为 `YYYY-MM-DD`），单元格值为「到 / 假 / 旷」。
- 运行目录下 `RollCallRecord/config.json`：保存点名规则。
- 再次运行时，只要 `RollCallRecord/record.xlsx` 存在且含有学生信息，即直接进入点名主界面。
- 同一天再次打开时，会跳过当天已点名的学生，只点当天还未记录的学生。

## 选择策略说明

- **计重复**：优先点历史记录轮次最少的学生（先点从没被记录过的，全都有记录后按轮次最少的点，
  轮次相同则整批候选）。
- **不计重复**：不考虑历史记录，全体学生等概率（随机）或按序号顺序。
- 每次会话内，同一学生在一轮中不会重复出现；一轮结束后自动开始新一轮。
